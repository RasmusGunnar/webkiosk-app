# Familiekalender branding
Temporary, original calendar/family symbol in `icon.svg`; no legacy or FCN images are used.

Run `npm run assets` from app to reproduce favicon, PWA icons, Android launcher/adaptive foreground and splash PNGs, and opaque 1024px iOS icon and splash. The icon itself has no baked-in rounded corners. Android adaptive masks provide the outer shape.

Final branding can replace this SVG and rerun the generator. No product code changes are required.
